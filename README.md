# The Funniest Toaster Error Message

A tiny Python program (`main.py`) that writes a single one-line toaster
error message to `/output/entry.txt`, as required by the make.fun
"The Funniest Toaster Error Message" competition.

The line (60 characters, inside the 120-character gate):

> ERROR: BAGEL TOO WIDE. I AM A TOASTER, NOT A MIRACLE WORKER.

## Run

```sh
python3 main.py
```

This creates `/output/entry.txt` containing the error message on a single line.
